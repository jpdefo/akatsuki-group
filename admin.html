Publish snapshot

GitHub Pages is read-only. Importing JSON here updates your browser locally; publishing is what makes the public site change.

Create a GitHub token ↗ Publish to GitHub Pages commits your current overrides (manual winners, kind/HLTB/month edits, pauses) straight to the repo using a GitHub token stored only in this browser. The public site rebuilds automatically (~1–2 min). First time? Click Create a GitHub token ↗, then set: Resource owner = your account, Repository access = Only select repositories → jpdefo/akatsuki-group, Permissions → Repository → Contents: Read and write. Generate it, copy it, then click Set / change GitHub token and paste it. Local alternative (from your PC): publish-snapshot.cmd Save current overrides first if you want HLTB, 10%, month, extra giveaway, or pause edits to become part of the next public snapshot. First-time setup on a fresh clone: run setup-publish.cmd once. It starts the local server, opens the bookmarklet helper and SteamGifts, waits for a fresh collector sync, refreshes Steam data, and publishes automatically.
