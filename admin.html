Publish snapshot

GitHub Pages is read-only. Publishing is what makes the public site change.

Create a GitHub token ↗ Publish to GitHub Pages commits your current overrides (manual winners, kind/HLTB/month edits, pauses) straight to the repo using a GitHub token stored only in this browser. The public site rebuilds automatically (~1–2 min). Force Steam data refresh triggers the daily refresh job now (playtime + achievements) instead of waiting for 06:00 UTC, then redeploys the site. Uses the same GitHub token; it finishes in a few minutes. First time? Click Create a GitHub token ↗ (opens the classic token page with the repo scope pre-checked) — add a name and an expiry, Generate, copy, then Set / change GitHub token and paste it. Collaborators must use a classic token: fine-grained tokens only list repos you own, so jpdefo/akatsuki-group won't appear for anyone but the owner. (The owner may instead use a fine-grained token scoped to this repo with Contents: Read and write.)
